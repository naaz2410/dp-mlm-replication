# DP-MLM Replication Project

## Overview

This repository contains the code, data, experiments, and analysis for
the replication and extension of:

> Differentially Private Text Rewriting Using Masked Language Models

The project aims to reproduce selected results from the original work
and investigate whether the reported findings hold when the method is
applied to new text data.

## Project Goals

1. Run the original DP-MLM code.
2. Reproduce selected experiments using the original data.
3. Compare our results with the results reported in the paper.
4. Investigate the behaviour of the method.
5. Create new text data using a reproducible process.
6. Apply DP-MLM to the new data.
7. Analyse whether the original findings continue to hold.

## Repository Structure

The repository will contain:

- Original/replication code
- Data and data-generation scripts
- Experiment scripts
- Results and analysis
- Project report and documentation
